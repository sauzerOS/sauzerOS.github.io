Bootstrap Process

Bootstrap process:

Enter the bootstrap chroot, configure package signing, initialize repositories, then build the devel tools and base system:

hk chroot /path-to-chroot
hk settings # generate/set package signature key
hk init-repos

# build the devel-tools
hk b --no-remote --no-devel bison
hk b --no-remote --no-devel --no-deps zlib-ng
hk b --no-remote --no-devel --no-deps ncurses
hk b --no-remote --no-devel --no-deps bzip2 gdbm
hk i --no-remote --no-deps lib32-ncurses
hk b --no-remote --no-devel --no-deps readline
hk b --no-remote --no-devel --no-deps perl
hk b --no-remote --no-devel --no-deps openssl
hk b --no-remote --no-devel --no-deps expat
hk b --no-remote --no-devel --no-deps python
pip install build flit_core installer
hk b --no-remote --no-devel --no-deps python-build python-flit-core python-installer python-packaging python-pyproject-hooks python-setuptools
hk alt discard-unmanaged # remove pip installs
hk b --no-remote --no-devel --no-deps bash
hk b --no-remote --no-devel --no-deps autoconf 
hk b --no-remote --no-devel --no-deps automake
hk b --no-remote --no-devel --no-deps attr
hk b --no-remote --no-devel --no-deps acl
hk b --no-remote --no-devel --no-deps gmp

locale-gen

All the packages for a basic sauzerOS chroot have been built and the chroot can be re-entered with systemd-nspawn -b -D /path-to-chroot.
